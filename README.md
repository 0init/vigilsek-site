# vigilsek.com

Static site for VigilSek. Served by GitHub Pages at the apex domain.

- `index.html` — single page, no build step, no dependencies
- `CNAME` — custom domain for GitHub Pages
- `.nojekyll` — serve `.well-known/` (Jekyll skips dot-directories by default)
- `.well-known/security.txt` — RFC 9116
